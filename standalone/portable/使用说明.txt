知会 · Windows 本地启动包

适用：Windows 10 / 11，x64。自带 Node.js 运行环境，不需要安装 Node.js、npm 或 Docker。

一、开始使用
1. 先完整解压压缩包，放在自己有写入权限的文件夹里。不要直接在压缩包内运行。
2. 双击“启动知会.cmd”。程序会自动打开默认浏览器。
3. 首次使用请注册邮箱账号；邮箱只是登录名，不发送验证邮件。密码至少 12 个字符。
4. 使用期间保留启动窗口。停止时双击“停止知会.cmd”，或在启动窗口按 Ctrl+C。

二、网页地址
默认地址为 http://127.0.0.1:4173/ 。端口被占用时会自动选择其他端口，实际地址显示在启动窗口，并记录到 data/launcher.json。
再次启动时优先使用上次端口。重复双击只会重新打开同一个面板。
这个地址只供本机使用；关闭程序或电脑后无法访问。它不提供公网分享。

三、账号和数据
压缩包内没有预设账号、真实事件、密码或 Agent 密钥。第一次启动会创建 data 文件夹。
账号、事件和密钥记录保存在 data/notice-inbox.sqlite；停止后再次启动仍然保留。
搬家或完整备份：先停止知会，再复制整个启动包文件夹，至少保留完整 data 文件夹。
升级时先停止程序，替换 app、runtime 和启动文件，保留原来的 data 文件夹。
已经使用过的启动包包含个人数据，分享给别人时应发送原始压缩包。

四、从原项目迁移
这个启动包使用自己的数据库，与源代码目录运行的网站相互独立。
事件可从原面板导出 JSON，再在新面板导入；账号与 Agent 密钥不会随 JSON 备份迁移，需要重新注册和创建密钥。
事件分类可在侧边栏“事件分类 → 管理”中新增、重命名和删除，按账号保存。重命名同步更新事件，删除分类时将事件移到“其他事件”，不会删除原文。“其他事件”为保留分类。JSON 备份同时包含分类，导入时会恢复缺少的分类。
“全部事件”同时显示普通事件、一次性日程和周期课程，课程通过类型标签、重复规则和下一次安排区分。周期系列只显示一张卡片，统计按卡片数计算；“事件时间表”按日期展开每一次课程。
已有“日程”“课程”分类继续保留，课程仍有独立默认归类。每个分类和对应卡片使用一致的颜色，自定义分类自动分色。类型与一次性／周期性独立，每周锻炼是事件，一次补课也可设为课程。课程也可改到其他已有分类或收藏，分类不会改变周期规则。重命名默认分类后，后续导入继续跟随；删除后回退到“其他事件”。取消记录默认隐藏，可显示取消项后恢复。
点击“添加事件”直接进入统一表单，只需标题即可保存，时间、原文和来源都可空。一个事件可保留多个明确时间点，各自选择不重复或每周重复；类型选择事件或课程，课程保留独立分类。已有个人日程也在同一表单编辑，原编号和调课规则保留。
“资料信息”表示收集的资料或备选活动，“纳入我的安排”表示决定执行的安排。有日期就能进入时间表，但资料信息不自动占用空闲；没有日期的事件仍保留在全部事件。旧普通事件默认资料信息，旧个人日程和课程默认我的安排。
个人任务、课表、时间偏好和修改历史都在同一个数据库中；事件 JSON 备份不包含全部时间管理数据，完整迁移请停止服务后复制整个 data 文件夹。

五、连接本机 Agent
登录面板，点击“连接 Agent”，选择仅导入、仅查询、查询＋导入或时间管理，创建密钥，并复制面板显示的 MCP 地址。
把地址和密钥配置到本机运行的 Agent。既要查也要保存原文事件时，选择“查询＋导入”；需要导入课表、修改日程、任务或偏好时选择“时间管理”。创建密钥后可点击“复制配置提示词”。密钥 90 天有效、可撤销；时间管理密钥可调整日程、任务、偏好及事件时间事项，但不能修改或删除原文事件。
可用工具：import_notices 导入事件；list_notices 搜索、分类和日期筛选；get_notice 读取完整原文。工具按密钥权限开放。
新事件可用 import_notices 保存，只有标题必填，根 participation 用 reference 表示资料信息、planned 表示纳入我的安排，events 的每个时间点可各自带 recurrence。课表截图仍推荐 import_events 并明确 recordType 为 course，个人日程用 schedule；默认省略 category，使用当前默认分类。不要为合并展示重复导入另一份记录。list_events 按日期读取并分页，recordType 可筛选两路数据中的事件或课程，all 还包含任务；是否占用个人时间依据 participation，不依据来源工具判断。
旧密钥升级后仍仅允许导入；查询需新建密钥，并更新 Agent 的凭据及工具白名单。升级程序前停止知会并备份 data，启动后数据库自动升级，原账号和事件保留。
原项目的密钥和 Codex 连接不会自动改为本启动包；如果地址变化，需要重新配置。
远程 Agent 不能通过 127.0.0.1 访问本机。截图识别、语音转写和内容整理由调用方 Agent 提供。
MCP 已连接后，在“连接 Agent → 快速连接”中下载知会 skill，完整解压并安装到 Agent 的技能目录。Codex 为 ~/.codex/skills/zhihui-notices/，其他客户端按各自的技能安装方式；安装后重新加载技能或开启新会话。
可以说“保存这条事件”“查奖学金材料要求”“最近有什么日程安排，做成时间轴”。skill 会核对原文，区分活动时间和截止日期，未知时间不猜测。Node.js 时间轴生成器无需额外依赖，也可由启动包 runtime/node.exe 运行；无文件执行能力时用聊天时间轴。
时间轴是当次查询快照，事件更新后需要重新生成。skill 不能代替 MCP 连接，也不能让旧的仅导入密钥自动获得读取权限。当前手机机器人方向暂缓。

六、常见问题
浏览器没有打开：复制启动窗口里的“访问地址”，粘贴到浏览器。
启动失败：确认已完整解压，文件夹有写入权限，并查看窗口中的错误提示。
停止提示“没有运行”：只会查找这个文件夹对应的知会，不会停止其他副本或原项目服务。
邮箱密码忘记了：当前没有邮件找回密码功能，请自行保管。
