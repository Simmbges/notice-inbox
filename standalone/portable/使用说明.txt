知会 · Windows 本地启动包

适用：Windows 10 / 11，x64。自带 Node.js 运行环境，不需要安装 Node.js、npm 或 Docker。

一、开始使用
1. 先完整解压压缩包，放在自己有写入权限的文件夹里。不要直接在压缩包内运行。
2. 双击“启动知会.cmd”。程序会自动打开默认浏览器。
3. 首次使用请注册邮箱账号；邮箱只是登录名，不发送验证邮件。密码至少 12 个字符。
4. 使用期间保留启动窗口。停止时双击“停止知会.cmd”，或在启动窗口按 Ctrl+C。

二、网页地址
默认地址为 http://127.0.0.1:4173/ 。端口被占用时会自动选择其他端口，实际地址显示在启动窗口，并记录到 data/launcher.json。
再次启动时优先使用上次端口。重复双击只会重新打开同一个面板。
这个地址只供本机使用；关闭程序或电脑后无法访问。它不提供公网分享。

三、账号和数据
压缩包内没有预设账号、真实通知、密码或 Agent 密钥。第一次启动会创建 data 文件夹。
账号、通知和密钥记录保存在 data/notice-inbox.sqlite；停止后再次启动仍然保留。
搬家或完整备份：先停止知会，再复制整个启动包文件夹，至少保留完整 data 文件夹。
升级时先停止程序，替换 app、runtime 和启动文件，保留原来的 data 文件夹。
已经使用过的启动包包含个人数据，分享给别人时应发送原始压缩包。

四、从原项目迁移
这个启动包使用自己的数据库，与源代码目录运行的网站相互独立。
通知可从原面板导出 JSON，再在新面板导入；账号与 Agent 密钥不会随 JSON 备份迁移，需要重新注册和创建密钥。

五、连接本机 Agent
登录面板，点击“连接 Agent”，创建导入密钥，并复制面板显示的 MCP 地址。
把地址和密钥配置到本机运行的 Agent。密钥 90 天有效、可撤销，只允许导入。
原项目的密钥和 Codex 连接不会自动改为本启动包；如果地址变化，需要重新配置。
远程 Agent 不能通过 127.0.0.1 访问本机。截图识别、语音转写和内容整理由调用方 Agent 提供。

六、常见问题
浏览器没有打开：复制启动窗口里的“访问地址”，粘贴到浏览器。
启动失败：确认已完整解压，文件夹有写入权限，并查看窗口中的错误提示。
停止提示“没有运行”：只会查找这个文件夹对应的知会，不会停止其他副本或原项目服务。
邮箱密码忘记了：当前没有邮件找回密码功能，请自行保管。
