Agent 导入密钥

为你的 Agent 创建一个专用密钥。它只能向你的通知库导入通知，不能查看或修改已有记录。每个密钥有效期为 90 天，可以随时撤销。

请现在复制，关闭后不再显示完整密钥。

将密钥填入 Agent 的认证配置，不要发到群聊或放进公开代码。

连接方式

支持 MCP 的 Agent：填写服务地址，认证方式选 Bearer Token，填入密钥。支持 HTTP 工具的 Agent：向导入地址发送 POST 请求，请求头使用 Authorization: Bearer 你的密钥。

连小理需要支持外部 MCP 或 HTTP 工具；能否接入仍需在它的平台实测。
