高级配置与权限说明

MCP 传输方式为 Streamable HTTP，认证方式为 Bearer Token。HTTP 接口使用相同认证，POST 导入、GET 查询，地址后追加 /事件编号读取详情。

工具按权限开放。仅查询与查询＋导入可读取时间表、任务、偏好和复盘；时间管理可创建、完成和调整任务，导入课表，修改整个周期或仅一次课程，并更新事件时间事项。密钥 90 天有效、可撤销；原文与事件删除不向 Agent 开放。旧密钥不自动获得时间管理权限。

读取权限会开放当前账号的事件及原文，请仅授予可信的 Agent。执行 MCP 工具的 Agent 需要能访问运行知会的电脑。
